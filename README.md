# MetaScan v2.3.1 — ファイルメタデータ検出・除去ツール (Windowsアプリ版)

アップロード前のファイルに個人情報・機密情報・偽装が含まれていないかをローカルで検査し、ワンクリックで除去するツールです。
**すべての処理はPC内で完結し、外部への送信は一切ありません。** 

## 使い方

- `dist\MetaScan-2.3.1.exe` を起動(インストール不要のポータブル版)
- ウィンドウにファイルをドラッグ&ドロップ、またはクリックして選択
- exeにファイルをドラッグ&ドロップして起動することも可能
- **右クリック統合**: トップバーの「🖱 右クリックメニューに登録」でエクスプローラーに「MetaScanでスキャン」を追加(HKCUのみ・管理者権限不要。Windows 11では「その他のオプションを表示」内に表示)。exeを移動したら再登録
- 「🧹 クリーンなコピーを保存」でメタデータを除去した `_clean` 付きコピーを生成(元ファイルは変更しない)。除去後は自動で再スキャンして結果を表示
- CLIモード: `MetaScan-2.3.1.exe --scan ファイル... [--out report.json]` でJSONレポートを出力

## v2.3の新機能 (v2.3.1でLZMA2対応を追加)

- **7-Zip(.7z)対応**: 自前のLZMA1/LZMA2デコーダー(lzma.js)を実装。LZMA圧縮されたヘッダーを展開してファイル一覧・実行ファイル混入・ヘッダー暗号化・パストラバーサルを検出。**Copy/LZMA/LZMA2(7zの既定)格納の中身はファイル単位に分割して完全再帰スキャン**(7z内のid_ed25519の鍵本体やEXIF等まで届く)。中身を展開できない場合(暗号化・BCJフィルター等)もファイル名から秘密鍵・認証情報を警告
- **RAR(.rar)対応**: RAR4/RAR5両形式でファイル一覧・暗号化・実行ファイル混入・パストラバーサルを検出。無圧縮(store)格納のファイルは中身まで再帰スキャン、ファイル名ベースの鍵検出は常時有効
- 汎用パターンスキャンが大きいファイルの**末尾256KB**も対象に(ログ末尾の認証情報等)

## v2.2の新機能

- **エクスプローラー右クリック統合**(登録/解除ボタン)
- **秘密鍵・認証情報検出の大幅強化**: PEM秘密鍵(従来)に加え、PGP秘密鍵・PuTTY PPK・Javaキーストア(JKS)・PKCS#12(.pfx/.p12)・DER形式・AWSシークレットアクセスキー・Azureストレージキー・GCPサービスアカウントJSON。`id_rsa`/`.env`/`credentials`等のファイル名ヒューリスティック(公開鍵`.pub`は除外)。ZIP内の`.env`や`id_rsa`も再帰検出

## v2.1の新機能

- **メタデータ除去**: JPEG(EXIF/XMP/IPTC/コメント/余剰データ)・PNG・WebP・MP3・docx/xlsx/pptx/ODF(作成者・会社名・日時・変更履歴の著者名・ZIP内部タイムスタンプ)。PDF/MP4は破損リスクがあるため非対応(理由と代替手段を表示)
- **「消したつもりが残ってる」検出**: EXIFサムネイル残存(編集前画像のプレビュー表示付き)、PDF増分更新(墨消し前の旧版残存)、JPEG終端以降の余剰データ、Excel非表示シート(hidden/veryHidden)、PowerPoint発表者ノート、Wordの未承認変更履歴・隠し文字
- **再帰スキャン**: ZIP・Office文書の内包ファイル(docx内の埋め込み画像のGPS等)を深さ2まで自動解析
- **Zone.Identifier (NTFS ADS)**: ファイルのダウンロード元URLを表示(Windowsアプリならでは)
- **並列化**: Web Workerプールで全CPUコアを使って並列解析(UIをブロックしない)。SHA-256はハードウェア支援(SubtleCrypto)で計算
  - GPUアクセラレーションはバイト列の逐次解析には効果がないため不採用(将来OCRを入れる場合はWebGPUが候補)

## ファイル構成

- `engine.js` — 解析エンジン本体(ブラウザ/Node両対応)
- `lzma.js` — LZMA1デコーダー(7zヘッダー/内包ファイル展開用)
- `cleaner.js` — メタデータ除去エンジン(ZIP再構築・CRC32含む)
- `worker-boot.js` — Web Workerエントリー(engine.jsと連結してBlobワーカー化)
- `index.html` — UI(ワーカープール・除去ボタン・サムネイルプレビュー)
- `main.js` / `preload.js` — Electronメインプロセス(CLIモード・Zone.Identifier読み取り)
- `test.js` — エンジン+クリーナーの自動テスト

## 旧版(metadata-scanner.html)から修正した主な不具合

1. **Office文書のメタデータが検出不能だった** — docx内のXMLはdeflate圧縮されており、生バイトへの正規表現は当たらない。ZIPセントラルディレクトリを解析し`DecompressionStream`で展開してから読むよう修正。
2. **PDFメタデータの見落とし** — Infoディクショナリは末尾にあることが多いのに先頭64KBしか見ていなかった。先頭+末尾を走査し、エスケープ文字列・16進文字列・UTF-16にも対応。
3. **EXIFのサブIFD未探索** — 撮影日時(0x9003)やGPS座標の実体はサブIFDにあり、旧版では「GPSあり」の表示のみ。サブIFDを辿り緯度経度を実数値まで復号するよう修正。
4. **ID3v2.4のフレームサイズ誤読** — v2.4はsyncsafe整数だが通常の32bitとして読んでいた。v2.2/2.3/2.4それぞれ正しく対応。
5. **拡張子偽装の誤検出** — ID3タグなしMP3(`FF FB`以外のフレーム同期含む)が「偽装」と誤判定されるなど。拡張子→許容マジックの対応表方式に変更。
6. **圧縮形式の高エントロピー誤警告** — PNG/JPEG/ZIP等はもともと高エントロピーで正常なのに「難読化の疑い」と警告していた。圧縮形式は除外し、EXEの高エントロピーのみ「パッカーの可能性」として警告。
7. **ファイル追加で前回の結果が消える** — 結果を消さず上に積む方式へ変更し、クリアボタンを追加。
8. **PE解析の不備** — `PE\0\0`シグネチャ未検証、タイムスタンプの符号あふれ(2038年問題)、将来日付の改ざん検出なし → すべて修正。
9. **拡張子なしファイルの誤表示** — `name.split('.').pop()`はドットがないとファイル名全体を返す。`lastIndexOf`方式に修正。
10. **その他** — ウィンドウ外ドロップでページ遷移してしまう問題、テーマ設定が保存されない問題、`copyReport`失敗時の通知、Officeテンプレートパス判定の脆弱な条件式(`indexOf`の和を比較)なども修正。
